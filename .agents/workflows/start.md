---
description: start the AlgoTrade-Navigator development server
---

1. Ensure dependencies are present
// turbo
2. Run `npm.cmd install` (if node_modules is missing)

3. Start the development server with turbopack
// turbo
4. Run `npm.cmd run dev`

5. Open the app in the browser
6. Once the server is ready (usually on port 3000), open http://localhost:3000
