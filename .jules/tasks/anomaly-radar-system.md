# Task: The Anomaly Radar System (End-to-End)

## 1. Executive Summary
This task defines the complete architecture for transitioning the AlgoTrade-Navigator from simple price-action tracking to **Deep Market Microstructure Analysis**. By capturing high-IQ order flow events (Whales, Icebergs, Spoofing, VPIN spikes, Liquidations) via a 24/7 background worker, the system will provide institutional-grade insights with minimal storage tax (< 10MB/day).

---

## 2. Gold Standard Protocol v2.0 Compliance
*   **Backward**: Fully integrates with existing `algo_trades.duckdb` and the `MicrostructureService.ts` physics engine.
*   **Memory/Tax**: Filter-first architecture. Discards 99% of normal order flow to save only high-conviction anomalies. Scales to 200+ assets with < 50MB RAM usage.
*   **Integrity**: Headless Node.js worker guarantees zero gaps in data collection, bypassing browser-closure fragmentation.
*   **Forward**: The analytical data model allows $O(1)$ querying for massive manipulations (e.g., "Total Spoofed Volume on BTCUSDT this week").

---

## 3. Backend Architecture: The Headless Sentry

### 3.1 `src/lib/headless-sentry.ts`
A standalone Node.js process (invoked via `npm run sentry` or PM2) that handles 24/7 WebSocket connections to Binance.
*   **Sharding Logic**: Opens 1 WebSocket connection per 200 symbols to strictly respect Binance API rate limits.
*   **Streams**: Subscribes to `@aggTrade`, `@markPrice@1s`, and `@forceOrder` (Liquidations).
*   **Filter Engine**: Passes incoming prints through `MicrostructureService`. If the resulting `entropyScore`, `vpin`, or `trade size` breach configured threshold parameters, the event is queued for database insertion.

### 3.2 DuckDB Schema Evolutions
Create a highly-indexed table designed for fast analytical aggregation.
```sql
CREATE TABLE IF NOT EXISTS microstructure_events (
    event_id VARCHAR PRIMARY KEY,
    timestamp BIGINT NOT NULL,
    symbol VARCHAR NOT NULL,
    event_type VARCHAR NOT NULL, -- 'WHALE_TX', 'ICEBERG', 'SPOOF_CANCEL', 'VPIN_SPIKE', 'LIQUIDATION', 'ENTROPY_SHIFT'
    price DOUBLE NOT NULL,
    volume_base DOUBLE NOT NULL,
    volume_usd DOUBLE NOT NULL,
    severity_score DOUBLE, -- 0.0 to 1.0 ranking of anomaly significance
    metadata VARCHAR -- JSON string for extra contextual data (e.g., "Short side liquidation")
);
```

## 4. Frontend UI/UX Architecture

### 4.1 The Engine Room (`/settings`)
*   **Sentry Control Board**: A new module inside Data Vault Settings.
*   **Toggles**: Start/Stop the background worker (communicates via an internal API route to the Node process).
*   **Configuration**: Sliders/Inputs for:
    *   Whale Size Minimum ($USD).
    *   VPIN Alert Threshold (e.g., > 0.8).
    *   Target Symbol List (Tier 1 vs Tier 2 selection).

### 4.2 The Command Center (`/manual`)
*   **Live Anomaly Feed**: A slim, non-intrusive "Squawk Box" ticker component docked to the right or bottom of the Manual Trading interface.
*   **Function**: Streams real-time flashes (via Server-Sent Events or local polling) of anomalies generated by the Sentry. Example: `🚨 [SOLUSDT] $2.5M Ask Wall Spoofed & Cancelled at $195.00`.

### 4.3 Deep Analysis: The New Radar Page (`/radar`)
A brand new, dedicated page built with Recharts/D3 for heavy quantitative visualization:
1.  **Manipulation Index Chart**: Pie/Bar chart comparing Real Executed Volume vs. Spoofed/Cancelled Volume per asset.
2.  **True Support/Resistance Heatmap**: Overlaying the mathematical sum of detected Iceberg liquidity zones against the current price.
3.  **Bot Dominance Ratio**: Time-series line chart tracking `entropyScore` regime shifts (Human vs. Synthetic control).
4.  **Smart Money Accumulation Tracker**: Divergence charts showing Price dropping while VPIN (Toxic Buy Flow) rises.
